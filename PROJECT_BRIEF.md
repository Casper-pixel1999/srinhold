# Amber Keep / Янтарная крепость

Russian medieval settlement and defense strategy for Yandex Games, desktop/laptop and mobile browsers. Grow a border settlement, balance food/construction resources, build defenses and survive readable siege waves. Map-led strategy with satisfying preparation and short tactical pressure.

Loop: gather -> build housing/production -> feed residents -> fortify/recruit -> survive siege -> expand. Early slice uses direct farm food; grain/flour/delivery logistics come later only by explicit task.

Visual direction: painted isometric sprites, warm stone/timber, amber accents, dark green parchment HUD. Map stays dominant, consistent sprite scale/anchors, compact touch controls. Legacy captures are visual references, not a panel-clutter requirement.

Release systems: construction, economy/population, defense/combat, one guided mission, local saves, responsive camera/UI, isolated Yandex SDK. Release one polished replayable mission first; three-map campaign/weather/advanced logistics are post-release candidates. No multiplayer/backend or mandatory account. First make gameplay good; monetization later.

Every player-facing string is Russian. Technical name Amber Keep; public title Янтарная крепость.
